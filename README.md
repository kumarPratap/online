🎨 Design Principles

The website should remain:

* Simple — avoid unnecessary complexity
* Responsive — work well on desktop, tablet, and mobile
* Readable — content should remain easy to understand
* Personal — the website should feel like my own digital space
* Maintainable — prefer clean and understandable code
* Expandable — new sections should be easy to add
* Long-lasting — avoid unnecessary dependencies where simple HTML/CSS is enough

CSS Philosophy

Prefer appropriate relative units and responsive techniques:

* rem → typography and spacing
* % → flexible widths
* vw / vh → viewport-relative sizing when appropriate
* clamp() → fluid sizing where useful
* aspect-ratio → responsive media
* Flexbox → layouts currently being learned
* CSS Grid → future layouts when useful

Avoid fixed pixel dimensions unnecessarily, but use px when it is the appropriate unit for a particular property.

📌 Content Principles

Before adding a new page or feature, ask:

1. Is it useful?
2. Does it belong on the website?
3. Can I keep it simple?
4. Will it still make sense later?
5. Does it help me learn something?
6. Can someone else benefit from it?

Avoid adding features simply because they are technically possible.

Useful over complicated.

⸻

🔄 Maintenance

The website should remain easy to maintain.

Before adding a major feature:

* Keep the HTML semantic and organized.
* Reuse existing CSS classes where appropriate.
* Avoid unnecessary duplication.
* Keep navigation consistent across pages.
* Test desktop and mobile layouts.
* Check embedded media before publishing.
* Keep file and folder names organized.
* Update the footer’s Last updated date when making meaningful changes.
* Update this README when the website structure or long-term plan changes.
