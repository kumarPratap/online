Notes & Knowledge

This page serves as a growing digital notebook where I document summaries, key concepts, quick references, and practical lessons from my studies.

Web Development Notes

  • HTML5 Semantics: Structure pages with semantic elements (`main`, `nav`, `section`, `article`, `header`, `footer`) for accessibility and search engine visibility.
  • CSS Layouts: Flexbox for one-dimensional linear layouts; CSS Grid for two-dimensional structures.
  • Responsive Design: Mobile-first media queries, relative units (`rem`, `%`), and fluid scaling.

Electrical Engineering References

  • Power Systems: Generation, transmission, and distribution fundamentals.
  • Protection & Relays: Overcurrent, differential, and distance protection principles in modern substations.
  • Numerical Relays: Microprocessor-based protection and control schemes.

Computer Science Concepts

  • Data Structures: Arrays, linked lists, stacks, queues, trees, and graphs.
  • Algorithms: Sorting, searching, and algorithmic complexity analysis (Big-O).
  • Version Control: Git branch management, atomic commits, and GitHub repository hosting.
